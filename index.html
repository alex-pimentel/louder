Como funciona o modo 100% client-side?
  • Voz: Web Speech API — vozes instaladas no seu sistema. Nada é enviado para a internet.
  • PDF: extraído localmente com PDF.js, dentro do navegador.
  • Privacidade: seus arquivos nunca saem do dispositivo. Não há backend.
  • Offline: após o primeiro acesso, um service worker guarda o app em cache para funcionar sem internet.

Atalhos: Espaço ler/pausar · Esc parar · ←/→ navegar trechos · Feito para funcionar sem internet 🔊
