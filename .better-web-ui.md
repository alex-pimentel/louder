# Louder — better-web-ui

## Design Context

### Users

Estudo e trabalho: pessoas que ouvem PDFs, artigos, documentação e páginas web
para absorver conteúdo com menos esforço — leitura em voz alta como ferramenta
de produtividade, não como brinquedo. Sessões potencialmente longas; o texto
é o protagonista e nada pode distrair da leitura.

### Brand Personality

Técnico e direto. Tom de voz em pt-BR, objetivo, sem enfeite. Emoção-alvo:
controle e eficiência — cara de ferramenta profissional (editor/IDE), não de
site institucional.

### Aesthetic Direction

- Layout de aplicação, não de página: área ampla de conteúdo à esquerda,
  painel estreito de controles à direita (~25%).
- Temas claro/escuro com alternador (começa no claro); o escuro tem alma de
  editor, sem neon nem glow gratuito.
- Tipografia legível para textos longos, hierarquia por espaçamento e peso
  antes de cor. Sem cards aninhados, sem hero, sem gradientes decorativos.
- Anti-referências: cara de landing page, glassmorphism genérico, roxo-para-azul,
  cards idênticos em grade.

### Implementation Defaults

Detectado no código (não inferido):

- App em DOM vanilla (`src/main.ts` + `index.html`) com shell React
  (`src/shell/`) do design system `@agenteresolve/ui` (git dependency).
- Estilo em CSS vanilla com variáveis (`src/style.css`); Tailwind v4 presente
  como plugin do Vite mas o layout atual é CSS próprio — preservar CSS próprio.
- Sem form library, sem data-grid, sem virtualização (não se aplicam).
- Testes: vitest (node) + 1 spec jsdom; e2e Playwright. Cobertura com
  thresholds mínimos que nunca podem cair.

### Design Principles

1. O texto manda: a área de leitura é o maior elemento da tela; controles
   recuam para o painel lateral e nunca competem por atenção.
2. Uma ação primária por momento: Ler/Pausar lidera; o resto é secundário
   e silencioso.
3. Hierarquia em escala de cinza primeiro: espaçamento, peso e tamanho
   antes de cor ou elevação.
4. Densidade honesta: agrupar por proximidade, não por caixas dentro de caixas.
5. Zero surpresa: comportamento de app desktop (atalhos, persistência local,
   offline-first) vale mais que efeito visual.
